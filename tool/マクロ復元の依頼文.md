# マクロ復元の依頼文（Claude にそのまま貼る）

---

処理件数集計のマクロが、セキュリティの処理で消えました。復元して、マクロを編集できる状態に戻してください。

- ブック：`C:\Users\kobay\projects\Kaizen\処理件数\処理件数集計.xlsm`（拡張子が .xlsx に変わっていることもあります）
- 復元スクリプト：`C:\Users\kobay\projects\Kaizen\処理件数\マクロ復元\restore_macros.ps1`
  - ブックの「マクロ保存」シート（名前「マクロ_モジュール名」の範囲）から全モジュールを組み直し、.xlsm で保存します。
  - 先にブックを `00.old\処理件数集計_マクロ復元前_日時` へバックアップします。
  - マクロ保存シートが消えている・壊れているときは `-FromSrc` を付けると、同じフォルダの `src\*.bas`（UTF-8 のテキストの控え）から組み直します。

## 手順
1. Excel でブックが開いていないか確認する（`~$処理件数集計.xlsm` があるか、Excel のプロセスで開いているブック）。開いていたら、保存して閉じるよう私に頼んでください。
2. 次を実行する。
   `powershell -NoProfile -ExecutionPolicy Bypass -File "C:\Users\kobay\projects\Kaizen\処理件数\マクロ復元\restore_macros.ps1"`
   - 「VBA プロジェクトにアクセスできません」と出たら、Excel のトラストセンターで「VBA プロジェクト オブジェクト モデルへのアクセスを信頼する」をオンにするよう、私に頼んでください。
3. 確認する。
   - VBE の「VBAProject のコンパイル」（CommandBars の Id 578）でエラーがないこと。隠れた Excel でコンパイルエラーが出るとダイアログで止まるので、ダイアログを閉じる見張りを付けて実行してください。
   - マクロ保存シートの内容と、各モジュールのコードが一致すること。
   - `RefreshDetail`（進捗（詳細）の作り直し）がエラーなく終わること。
4. 結果を報告する（モジュールごとの行数、バックアップの場所）。

## マクロを編集するときの注意（このブック固有）
- モジュール：modImport（取込・操作シート）、modRecord（状況を記録）、modDailyRec（日別を記録）、modCalendar（日付・休日）、modWork（稼働実績・業務マスタ）、modDetail（進捗（詳細）・スキルマップ・事由比率・簡易版との連動）、modBackup（マクロ保存シート）、ThisWorkbook（保存のたびにマクロ保存シートを更新）。
- 変更は、まずコピーで試してから本番に入れる。本番を書き換える前に `00.old` へ `処理件数集計_<変更内容>前_<yyyymmdd>.xlsm` でバックアップする。
- コードの差し替えは、PowerShell の Excel COM で `CodeModule.DeleteLines` ＋ `AddFromString`（UTF-8 で読んだ文字列を渡す）。PowerShell 5.1 のスクリプトは UTF-8（BOM 付き）で保存する。
- VBA に入れられない文字：−（U+2212）・〜（U+301C）・▶ は化ける。－（U+FF0D）・～（U+FF5E）・ChrW(&H25B6) を使う。組み込み関数と同じ名前の変数（例：mId と Mid）は使わない。
- このPCの Excel は LET・XLOOKUP・FILTER・SEQUENCE は使えるが、MAP・LAMBDA・BYCOL は使えない（#NAME?）。
- 折りたたんだ行があるシートでは、End(xlUp) が最終行を取りこぼす。最終行は UsedRange から取る。
- 進捗（簡易版）・進捗（詳細）の言葉は統一している：確認中（1次／2次）、認定件数（1次）＝登録、認定件数（2次）＝ＳＶ承認、見込み認定件数（1次／2次）、確認中（見込み含む）、残数。
- 保存すると ThisWorkbook の BeforeSave がマクロ保存シートを最新のコードで書き直す。復元したあとは、マクロを有効にして一度保存しておく。
