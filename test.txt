（１）A2:C2 に一意の組み合わせを展開
　セル A2 に
　　=UNIQUE( Sheet1!E2:G1000 )

（２）D2 に「処理案件数」を持ってくる
　セル D2 に
　　=XLOOKUP(
　　　1,
　　　( Sheet1!E$2:E$1000 = $A2 ) *
　　　( Sheet1!F$2:F$1000 = $B2 ) *
　　　( Sheet1!G$2:G$1000 = $C2 ),
　　　Sheet1!I$2:I$1000
　　)

（３）E2 に「所要時間」を持ってくる
　セル E2 に
　　=XLOOKUP(
　　　1,
　　　( Sheet1!E$2:E$1000 = $A2 ) *
　　　( Sheet1!F$2:F$1000 = $B2 ) *
　　　( Sheet1!G$2:G$1000 = $C2 ),
　　　Sheet1!L$2:L$1000
　　)
